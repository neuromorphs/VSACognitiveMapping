2 · Memory recall

Ask the memory where it is, one frame at a time

The memory is a single vector holding every frame's appearance bound to the pose it was seen from. To localise, take this frame's descriptor, divide it out, and correlate what is left against a grid of candidate positions — bright is where the memory believes it is. Switch encoder to see the same query answered by a memory built from a different backbone.
